# Waypoint 12.1.0 — All-in Candidate

Adds Waypoint Copilot, global trip search, reusable trip templates, and consolidates the existing V11 toolset.

## Included
- Copilot answers common questions from locally saved trip data before using Gemini.
- Global search across activities, bookings, expenses, tasks, memories and notes.
- Reusable templates for itinerary structure and packing lists. Templates intentionally exclude private vault contents, expenses, bookings/confirmations, memories and collaboration credentials.
- Existing V11 features remain: Today, itinerary, route optimization, smart booking import, Wallet, budgets, packing, polls, tasks, memories, flight journal/live-provider hook, encrypted vault, collaboration, offline package, backups, AI quotas, Premium controls, legal bilingual flow.

## External configuration still required
App Store/Google Play signing and native purchases, push notification credentials, Gemini/Google Routes/Places keys, flight provider key, Stripe and production domain configuration cannot be made live without the corresponding owner accounts/credentials.
