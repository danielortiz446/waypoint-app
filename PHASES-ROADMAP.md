# Waypoint expansion roadmap — V10.4.0

1. **Implemented in this version:** AI selection and batch itinerary actions; richer place cards with Maps + copy; shared-trip activity RSVPs; on-demand flights with AirLabs optional; configurable in-app reminders; category filtering in local encrypted wallet; offline status transparency.
2. **Next web phase:** Fully interactive itineraries with day previews, Google Places operating hours and photos with proper attribution/licensing, conflict-safe RSVP sync, richer group notification center and robust offline attachment manifests.
3. **Native iOS phase:** Generate and compile native Xcode project on Mac; native encrypted storage migration, Face ID integration, APNs remote push and secure device tokens; widgets/Live Activities with Swift extensions. **Not implemented in this ZIP.**
4. **External integration phase:** Flight subscription/cost controls, scheduled flight refresh and alerts (with opt-in); advertising, native billing and premium entitlement enforcement. **Not implemented in this ZIP.**

Always preserve local data and Railway persistent volume.
